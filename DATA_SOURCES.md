## Transformations applied

| Step | Script | What it does |
|---|---|---|
| Download + provenance | `pipeline/spike/01-download.mjs` | Fetches each source; records size, sha256 and download timestamp |
| Index build | `pipeline/spike/03-build-index.mjs` | Builds the form→lemma index from `forms[]` and `form_of` records; assigns canonical IDs; merges records sharing word+pos+etymology |
| Frequency aggregation | `pipeline/spike/04-form-lemma.mjs` | Aggregates OpenSubtitles token counts into lemma ranks (citation-first ambiguity policy) |
| Entry build + conjugations | `pipeline/spike/05-build-sample.mjs` | Builds DictEntry records, sorts Mexico-labeled senses first, joins Jehle conjugations (ustedes-first, vosotros collapsed) |
| Examples | `pipeline/spike/06-join-examples.mjs` | Attaches ≤3 Tatoeba es↔en pairs, each with sentence ID, contributor, license and URL |
| Report | `pipeline/spike/07-report.mjs` | Produces this file, the size estimate and the review records |
