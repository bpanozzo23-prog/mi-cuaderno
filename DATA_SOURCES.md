## Transformations applied

| Step | Script | What it does |
|---|---|---|
| Download + provenance | `pipeline/build/01-download.mjs` | Fetches each source; records size, sha256 and download date; runs the standing source re-checks |
| Index build | `pipeline/build/02-build-index.mjs` | Builds the form→lemma index from `forms[]` and `form_of` records; assigns canonical IDs; merges records sharing word+pos+etymology |
| Frequency ranking | `pipeline/build/03-frequency.mjs` | Aggregates OpenSubtitles token counts into lemma ranks: citation-form-first, with ambiguous inflected tokens allocated in proportion to each candidate's unambiguous evidence |
| Entry build | `pipeline/build/04-entries.mjs` | Builds DictEntry records for the top ~10k lemmas; sorts Mexico-labeled senses first; joins Jehle conjugations |
| Examples | `pipeline/build/05-examples.mjs` | Attaches ≤3 Tatoeba es↔en pairs, each with sentence ID and contributor for both sides |
| Conjugations | `pipeline/build/06-conjugate.mjs` | Extracts tables from kaikki's tagged forms for the verbs Jehle lacks; validates against Jehle cell by cell |
| Packaging | `pipeline/build/07-package.mjs` | Compacts entries, builds the form and English indexes, splits into verified chunks under `public/dict/` |
| Documentation | `pipeline/build/08-report.mjs` | Produces this file and the review records |

## How attribution reaches the reader

Every example sentence stores its Tatoeba sentence ID and contributor **for both the Spanish
and the English side**, since each side is a separate contribution by a separate person. The
license (`CC BY 2.0 FR`) and the URL template (`https://tatoeba.org/en/sentences/show/<id>`)
are constants recorded once in the bundle manifest's attribution block rather than duplicated
across all 56,420 sentence sides; the app renders ID, contributor, license and link on every
example. The Ajustes screen shows the installed dataset version and this attribution.
